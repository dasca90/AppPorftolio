# Alexandru Dascalescu — Portofoliu AI & Automatizare

Portofoliu profesional pentru roluri de **AI Automation**, software tooling și workflow automation.

## Poziționare

Sunt tehnician de proiectare CAD cu experiență în instalații electrice, sanitare, ventilație și sisteme fotovoltaice, plus **3 ani experiență practică în AI & automatizare** prin proiecte software personale.

Nu mă poziționez ca specialist pur în machine learning, ci ca un builder practic: folosesc AI, automatizare, procesare de date, API-uri și aplicații software pentru a reduce munca manuală și a transforma procese tehnice în tool-uri utile.

## Proiecte principale

- **Trading Bot Dashboard** — aplicație pentru scanare piață crypto, reguli de decizie, jurnal de tranzacții și notificări automate.
- **Solar Pre-Design & Quotation Platform** — platformă pentru pre-proiectare solară 2D, layout panouri, date tehnice și ofertare.
- **Scan&Clean** — tool pentru scanarea folderelor/HDD-urilor și identificarea fișierelor care ocupă cel mai mult spațiu.

## Competențe urmărite în portofoliu

- AI-assisted development
- Workflow automation
- Python / React / TypeScript
- API integration
- Data processing
- Technical documentation
- AutoCAD / MEP / PV design
